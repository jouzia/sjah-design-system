# SJAH Design System Vault

A reusable design-to-code system for SJAH projects. Use this vault as the source of truth for visual identity, interaction patterns, accessibility, authentication, shared components, and project-specific implementation decisions.

## Start here
1. Open **00 - Start Here/Design System Home.md**.
2. Review **01 - Design System/Design Tokens.md** and **01 - Design System/Interaction & Motion.md**.
3. Use the project kickoff template in **03 - Templates/New Project Kickoff.md** for every new project.
4. Keep the real implementation in the project's code repository; this vault defines the standard and records decisions.

## Important asset note
The included `05 - Assets/cat-lets-go.png` is the “Let’s Go..” cat image supplied with the request. The separate SJAH emblem/logo and AI mascot reference image were not present as standalone assets in the files available for this pack. Add the original transparent logo and mascot files to `05 - Assets/` when available, then update the asset manifest. Do not use a guessed URL or a placeholder image in production.

## Design principles
- Consistent shared identity; project-specific content remains distinct.
- Responsive, accessible, keyboard-friendly interfaces.
- Motion should clarify transitions, not delay task completion.
- Security and real authentication take precedence over decorative mockups.
- Prefer reusable tokens/components over copying one-off CSS.
